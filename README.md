# Inkwell — turn your handwriting into a font, then type in it

Native SwiftUI + PencilKit app for iPad: capture your handwriting character by
character in a guided wizard, then render any typed text in your own hand on
imported paper photos — with automatic scaling to the line spacing. Built and
shipped entirely from GitHub Actions — no Mac, no paid developer account.

**Target device:** iPad (10th generation, 10.9-inch) + Apple Pencil (USB-C).
**Minimum OS:** iPadOS 17.

## How it works

1. **My Hands → create a handwriting set.** You're guided through every
   character: uppercase, lowercase, digits, German (Ä Ö Ü ä ö ü ß), and a
   signs/punctuation library (≈20 symbols incl. €). Draw each character on
   guide lines (ascender / x-height / baseline / descender) with a faint
   reference letter behind. Skip anything you don't need — undrawn characters
   are simply left out of rendered text.
2. **Shortcuts:** umlauts auto-build from the base letter (draw “a” once, tap
   the wand on “ä” — the dots are stamped automatically). Clear/redraw any
   character anytime.
3. **Documents → create a document.** Type your text, pick the hand, choose a
   background: **import a photo of your paper** (worksheets, letterhead…) or
   blank lined/grid/dotted paper. Set the **line spacing** to match your paper
   (with red baseline guides to check) — the handwriting **scales
   automatically** to that spacing, so size and rhythm match your natural
   writing. Letter spacing, text size multiplier, ink color, and space width
   (per hand) are adjustable.
4. **Export** as high-resolution PNG or PDF via the share sheet.

### How the scaling works

Every glyph is captured on a screen-height canvas with a fixed baseline
fraction, then normalized to a canonical cell on save. When composing, strokes
are scaled about the baseline by `lineSpacing / naturalLineAdvance` — so your
handwriting grows or shrinks with the line grid while sitting exactly on it.
Word wrapping honors each glyph's real drawn width.

## Project layout

```
project.yml                       XcodeGen manifest — CI generates Inkwell.xcodeproj
Inkwell/
  App/                            entry + split view (sidebar: My Hands / Documents)
  Models/Handwriting.swift        character sets, HandwritingSet, HandDocument
  Models/PaperTemplate.swift      blank-paper templates (plain/lined/grid/dots)
  Services/GlyphRenderer.swift    metrics, composing, word wrap, page/PDF rendering, umlaut dots
  Services/HandStore.swift        hands + glyph persistence (PKDrawing per character)
  Services/DocumentStore.swift    documents, background images, thumbnails
  Views/                          capture wizard, progress grid, document editor, tool block
  Design/Theme.swift              ink palette, cover themes, paper colors
.github/workflows/ios.yml         CI: unsigned device build → sideloadable IPA
```

**Do not commit or hand-edit `Inkwell.xcodeproj`** — it is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`.

## Build & install on your iPad

Every push to `main` runs one job on a GitHub macOS runner: generates the
Xcode project, compiles a Release build for a physical iPad with code signing
disabled, and uploads an unsigned `.ipa` artifact.

1. GitHub → **Actions** → latest run → download **Inkwell-unsigned-ipa**, unzip.
2. Sideload with **Sideloadly** (Windows/macOS, signs with your Apple ID at
   install time) or **SideStore** + AltServer-Linux.
3. Settings → General → VPN & Device Management → trust your certificate.

Free Apple ID: signature expires after 7 days (re-sideload to refresh), max 3
sideloaded apps.

> Keep the repo **private**: artifacts on private repos are only visible to you.

## Tips for good results

- Draw each character with **one connected stroke where you would write it** —
  the vector eraser removes whole strokes while fine-tuning.
- Keep the pencil on the guide lines; the baseline is what every glyph hangs
  from in rendered text.
- For documents on photos: calibrate line spacing with the red guides turned
  on, then fine-tune “Text size” to taste.
