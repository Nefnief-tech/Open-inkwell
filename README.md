# Inkwell — a GoodNotes-style handwriting app for iPad

Native SwiftUI + PencilKit note-taking app, built and shipped entirely from
GitHub Actions — no Mac required.

**Target device:** iPad (10th generation, 10.9-inch) + Apple Pencil (USB-C).
**Minimum OS:** iPadOS 17.

## Features (v1)

- Notebooks in a sidebar, page-thumbnail gallery per notebook
- Full-bleed drawing canvas with `PKCanvasView` + floating `PKToolPicker`
  (pen, marker, eraser, ruler, undo/redo, colors — all built in)
- Palm rejection while the Pencil is in use; optional finger drawing toggle
- Autosave (debounced) + save on app backgrounding
- Page thumbnails regenerated on every save; delete/rename via context menus
- On-device storage: `Documents/Notebooks/<uuid>/` (JSON manifest +
  PencilKit `.drawing` files + PNG thumbnails)

> **Apple Pencil (USB-C) hardware note:** this pencil has **no pressure
> sensor** — that is true in GoodNotes too. It *does* support tilt (use the
> marker/watercolor inks for shading) and low-latency input. Stroke width is
> set per tool. Palm rejection is handled by iPadOS/PencilKit.

## Project layout

```
project.yml                  XcodeGen manifest — CI generates Inkwell.xcodeproj from this
Inkwell/
  App/                       @main entry, root NavigationSplitView
  Models/                    Notebook / PageInfo
  Services/LibraryStore.swift  persistence + CRUD (@Observable)
  Views/                     sidebar, page grid, drawing canvas, settings
  Resources/Assets.xcassets  app icon + accent color
.github/workflows/ios.yml    CI: simulator build, signed IPA, optional TestFlight
```

**Do not commit or hand-edit `Inkwell.xcodeproj`** — it is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`. Change
`project.yml` instead.

## CI — what happens on every push

1. `build` job on a macOS runner: installs XcodeGen, generates the project,
   and compiles against an iPad (10th generation) simulator. This is the
   compile-correctness gate — it catches Swift errors without any local Mac.
2. `package` job (only when signing is configured, see below): archives the
   app and exports a **signed ad-hoc IPA** as a downloadable artifact.
3. `testflight` job (optional): uploads to TestFlight via fastlane.

## Getting the app on your iPad (Linux-only workflow)

### One-time: what you need

- An **Apple Developer Program** membership ($99/yr) for TestFlight, or a
  free Apple ID for ad-hoc signing (7-day expiry, max 3 apps).
- Your iPad's **UDID** — on Linux: `sudo pacman -S libimobiledevice`, plug
  the iPad in, run `idevice_id -l`.
- `openssl` (you have it).

### 1. Create a signing certificate — no Mac needed

```bash
openssl genrsa -out inkwell.key 2048
openssl req -new -key inkwell.key -out CSR.csr \
  -subj "/CN=iPhone Developer: Your Name/emailAddress=you@example.com/C=DE"
```

Upload `CSR.csr` at [developer.apple.com → Certificates](https://developer.apple.com/account/resources/certificates/list)
→ **Create Certificate → Apple Development** (or Apple Distribution for
TestFlight). Download the `.cer`, then bundle it into a P12:

```bash
openssl x509 -in apple.cer -inform DER -out apple.pem
openssl pkcs12 -export -out inkwell.p12 -inkey inkwell.key -in apple.pem
base64 -w0 inkwell.p12   # this is BUILD_CERTIFICATE_BASE64
```

### 2. Register the app + device, create a provisioning profile

1. **Identifiers → + → App IDs → App**: bundle id `com.fabi.inkwell`
   (or your own — also change it in `project.yml` and in the workflow's
   `ExportOptions` step).
2. **Devices → +**: add your iPad's UDID (ad-hoc/development only).
3. **Profiles → + → iOS App Development** (or Ad Hoc): pick the App ID +
   certificate + your iPad. Download the `.mobileprovision`:
   `base64 -w0 profile.mobileprovision` → `PROVISIONING_PROFILE_BASE64`.

### 3. Configure the repo

Set repo **variables** (Settings → Secrets and variables → Actions → Variables):

| Variable | Value |
|---|---|
| `SIGNING_ENABLED` | `true` |
| `TESTFLIGHT_ENABLED` | `true` only if you want TestFlight uploads |

Set repo **secrets**:

| Secret | Meaning |
|---|---|
| `BUILD_CERTIFICATE_BASE64` | base64 of the `.p12` |
| `P12_PASSWORD` | password you chose in `openssl pkcs12 -export` |
| `KEYCHAIN_PASSWORD` | any strong random string (CI-ephemeral keychain) |
| `TEAM_ID` | your 10-char Apple Developer Team ID |
| `PROFILE_NAME` | exact name of the provisioning profile |
| `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8_BASE64` | App Store Connect API key (TestFlight only; base64 the `.p8`) |

### 4. Install

- **Signed IPA artifact** → sideload with
  [AltStore/SideStore](https://sidestore.io/) or Sideloadly (both run on
  Windows/Linux via USB), or Apple Configurator if you borrow a Mac.
- **TestFlight** (paid account): install TestFlight from the App Store on
  the iPad, accept the invite — updates arrive automatically on every push.
