# Inkwell — a GoodNotes-style handwriting app for iPad

Native SwiftUI + PencilKit note-taking app, built and shipped entirely from
GitHub Actions — no Mac, no paid developer account required.

**Target device:** iPad (10th generation, 10.9-inch) + Apple Pencil (USB-C).
**Minimum OS:** iPadOS 17.

## Features (v2)

- **Library** — GoodNotes-style grid of notebook covers (8 color themes,
  spine + title), notebook rename / duplicate / delete via context menus
- **Sidebar** — custom list with mini covers, page counts, relative dates
- **Pages** — thumbnail gallery with page numbers and template badges
- **Custom tool block** — floating pencil toolbar (pen / pencil / marker /
  vector eraser, 8 ink colors, 3 widths, undo/redo, hideable); replaces the
  system `PKToolPicker`; tool choices persist between sessions
- **Paper templates** — plain, lined, grid, dotted; per page (chosen when
  creating) plus a notebook default; baked into saved thumbnails
- Cream paper, palm rejection while the Pencil is in use, finger drawing toggle
- Autosave (debounced) + save on app backgrounding
- On-device storage: `Documents/Notebooks/<uuid>/` (JSON manifest +
  PencilKit `.drawing` files + PNG thumbnails)

> **Apple Pencil (USB-C) hardware note:** this pencil has **no pressure
> sensor** — that is true in GoodNotes too. It *does* support tilt (use the
> marker/watercolor inks for shading) and low-latency input. Stroke width is
> set per tool. Palm rejection is handled by iPadOS/PencilKit.

## Project layout

```
project.yml                  XcodeGen manifest — CI generates Inkwell.xcodeproj from this
Inkwell/
  App/                       @main entry, root NavigationSplitView
  Models/                    Notebook / PageInfo
  Services/LibraryStore.swift  persistence + CRUD (@Observable)
  Views/                     sidebar, page grid, drawing canvas, settings
  Resources/Assets.xcassets  app icon + accent color
.github/workflows/ios.yml    CI: unsigned device build → sideloadable IPA
```

**Do not commit or hand-edit `Inkwell.xcodeproj`** — it is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`. Change
`project.yml` instead.

## Build & install on your iPad

Every push to `main` runs one job on a GitHub macOS runner: it generates the
Xcode project, compiles a Release build for a physical iPad with **code
signing disabled**, and packages the result as an unsigned `.ipa`.

1. Open your repo on GitHub → **Actions** → latest run on `main` →
   download the **Inkwell-unsigned-ipa** artifact and unzip it.
2. Sideload it (the tool signs the IPA with your Apple ID at install time):
   - **Sideloadly** (Windows/macOS): plug the iPad in via USB, drag the
     `.ipa` in, enter your Apple ID, click Start. Works with a free account.
   - **SideStore** (iPad-side, pairs with AltServer): on Linux use
     [AltServer-Linux](https://github.com/NyaMisty/AltServer-Linux) to pair,
     then install the IPA from the Files app via SideStore.
3. On the iPad: Settings → General → VPN & Device Management → trust your
   Apple ID certificate.

**Free Apple ID limits:** the signature expires after **7 days** (re-sideload
to refresh), maximum 3 sideloaded apps. A paid Apple Developer account lifts
both limits — later, the same CI can be extended to produce a properly signed
IPA or TestFlight build (this setup existed in git history).

> Keep the repo **private**: artifacts on private repos are only visible to
> you. Anyone could download them from a public repo.

## Local development (optional, only if you ever get a Mac)

```bash
brew install xcodegen
xcodegen generate
open Inkwell.xcodeproj
```
